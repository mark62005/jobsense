## 🌳 Git Workflow

### Branch Strategy

```
main        → production
develop     → staging / integration
feature/*   → new features
fix/*       → bug fixes
chore/*     → tooling & configs
```

### Commit Convention

```
feat: add AI resume generation
fix: prevent duplicate resumes
refactor: extract resume service
chore: update prisma client
docs: update README
```

This keeps history clean and readable for teams and reviewers.
